# Анализ проекта Parser

## Обзор проекта

Это Node.js приложение для парсинга (извлечения) каталогов с веб-сайта **https://www.tus.si**. Проект автоматически скачивает PDF-файлы каталогов и сохраняет метаданные о них в формате JSON.

## Основные компоненты

### 1. **index.js** - Точка входа приложения

Основной файл, который запускает процесс парсинга:

```javascript
import { fetchCatalogs, downloadPDF, saveJSON } from "./services.js";
const url = "https://www.tus.si/#s2";

(async function main() {
  const catalogs = await fetchCatalogs(url);  // Получение списка каталогов
  await downloadPDF(catalogs);                 // Скачивание PDF файлов
  await saveJSON(catalogs);                    // Сохранение метаданных в JSON
})();
```

**Функциональность:**
- Определяет целевой URL для парсинга
- Последовательно вызывает три основные функции:
  1. Извлечение информации о каталогах
  2. Скачивание PDF файлов
  3. Сохранение метаданных

### 2. **services.js** - Модуль с основными функциями

Содержит три ключевые функции:

#### 2.1. `getHTML(url)`
- Вспомогательная функция для получения HTML содержимого страницы
- Использует библиотеку **axios** для HTTP запросов
- Возвращает объект **cheerio** для парсинга HTML

#### 2.2. `fetchCatalogs(url)`
- **Назначение**: Извлекает информацию о каталогах с веб-страницы
- **Процесс**:
  1. Загружает HTML страницы
  2. Ищет элементы списка каталогов по селектору `#s2 > div > ul li`
  3. Для каждого каталога извлекает:
     - `title` - название каталога
     - `link` - ссылка на страницу каталога
     - `timeStart` - дата начала действия каталога
     - `timeEnd` - дата окончания действия каталога
     - `savePDF` - ссылка на PDF файл каталога
- **Возвращает**: Массив объектов с информацией о каталогах
- **Обработка ошибок**: Логирует ошибки в консоль

#### 2.3. `downloadPDF(catalogs)`
- **Назначение**: Скачивает PDF файлы каталогов
- **Процесс**:
  1. Обрабатывает все каталоги параллельно (Promise.all)
  2. Для каждого каталога:
     - Извлекает имя файла из URL
     - Скачивает PDF как бинарные данные
     - Создает папку `downloads/` если её нет
     - Сохраняет файл в `downloads/`
     - Выводит сообщение об успешной загрузке
- **Обработка ошибок**: Логирует ошибки загрузки отдельных файлов

#### 2.4. `saveJSON(catalogs)`
- **Назначение**: Сохраняет метаданные о каталогах в JSON файл
- **Процесс**:
  1. Преобразует массив каталогов в JSON с форматированием
  2. Создает папку `catalogs/` если её нет
  3. Сохраняет в файл `catalogs/catalogs.json`
  4. Выводит сообщение об успешном сохранении
- **Обработка ошибок**: Логирует ошибки сохранения

## Используемые технологии и библиотеки

### 3.1. **Node.js с ES модулями**
- Проект использует современный синтаксис ES модулей (`type: "module"` в package.json)
- Импорты через `import` вместо `require`

### 3.2. **Зависимости (package.json)**

1. **axios (v1.7.2)**
   - Библиотека для выполнения HTTP запросов
   - Используется для:
     - Загрузки HTML страниц
     - Скачивания PDF файлов

2. **cheerio (v1.0.0-rc.12)**
   - Быстрая и гибкая библиотека для парсинга HTML
   - Реализует jQuery-подобный синтаксис для работы с DOM
   - Используется для извлечения данных из HTML

3. **fs (встроенный модуль Node.js)**
   - Работа с файловой системой
   - Создание директорий
   - Сохранение файлов

## Рабочий процесс приложения

```
1. Запуск приложения (npm run start)
           ↓
2. Загрузка HTML со страницы https://www.tus.si/#s2
           ↓
3. Парсинг HTML и извлечение информации о каталогах
           ↓
4. Параллельное скачивание всех PDF файлов в папку downloads/
           ↓
5. Сохранение метаданных в catalogs/catalogs.json
           ↓
6. Завершение работы
```

## Особенности реализации

### Преимущества:
1. **Модульная структура** - разделение логики на отдельные функции
2. **ES модули** - современный синтаксис JavaScript
3. **Асинхронность** - использование async/await для читаемого кода

5. **Обработка ошибок** - try/catch блоки в критических функциях
