# Parser

Web scraper для автоматического скачивания каталогов с сайта https://www.tus.si

## 📋 Описание / Description

**[RU]** Приложение для автоматического извлечения информации о каталогах с веб-сайта TUS и скачивания их PDF версий.

**[EN]** Application for automatic extraction of catalog information from the TUS website and downloading their PDF versions.

## 🚀 Запуск / Getting Started

### Установка зависимостей / Install Dependencies:
```bash
npm install
```

### Запуск приложения / Run Application:
```bash
npm run start
```

## 📂 Результаты работы / Results

После завершения работы скрипта / After script completion:
- 📥 **downloads/** - все скачанные PDF каталоги / all downloaded PDF catalogs
- 📄 **catalogs/catalogs.json** - информация о каталогах в JSON формате / catalog information in JSON format

## 🛠 Технологии / Technologies

- **Node.js** (ES Modules)
- **axios** - HTTP клиент / HTTP client
- **cheerio** - HTML парсер / HTML parser
